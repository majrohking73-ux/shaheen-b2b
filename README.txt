GROUP TICKET FEATURES
- Each group has its own date
- Each group has its own seat inventory
- Each group has its own B2B price
- BOOK NOW button for every group
- Professional passenger booking drawer/form
- Full Name, Passport, Nationality, DOB, Gender, Passport Expiry
- Contact / WhatsApp, passenger count and notes
- Total amount is calculated automatically
- WhatsApp request is prepared for +92 349 8942034
- Admin can add/delete groups with different dates, seats and prices
